zone or local<br/> calendar, encoded as a count of seconds and fractions of seconds at<br/> nanosecond resolution. The count is relative to an epoch at UTC midnight on<br/> January 1, 1970, in the proleptic Gregorian calendar which extends the<br/> Gregorian calendar backwards to year one.<br/><br/> All minutes are 60 seconds long. Leap seconds are "smeared" so that no leap<br/> second table is needed for interpretation, using a [24-hour linear<br/> smear](https://developers.google.com/time/smear).<br/><br/> The range is from 0001-01-01T00:00:00Z to 9999-12-31T23:59:59.999999999Z.
