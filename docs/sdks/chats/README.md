# Chats

## Overview

### Available Operations

* [attach_agent](#attach_agent) - External API users
* [bookmark](#bookmark) - BookmarkChat
* [check_health](#check_health) - CheckHealth
* [delete](#delete) - DeleteChat
* [dismiss_questions](#dismiss_questions) - DismissQuestions
* [get_api_answer](#get_api_answer) - GetAPIChatAnswer
* [get](#get) - GetChat
* [get_artifacts_summary](#get_artifacts_summary) - GetChatArtifactsSummary
* [get_chat_execution_timing](#get_chat_execution_timing) - GetChatExecutionTiming
* [get_all](#get_all) - GetChats
* [get_completion_parameters_batch](#get_completion_parameters_batch) - GetCompletionParametersBatch
* [get_llm_usage](#get_llm_usage) - GetLlmUsage
* [get_members_with_chats](#get_members_with_chats) - List distinct chat creators the user can access
* [query_one_shot](#query_one_shot) - QueryOneShot
* [reject_ontology_change](#reject_ontology_change) - RejectOntologyChange
* [run](#run) - RunChat
* [submit_context_prompt_change](#submit_context_prompt_change) - SubmitContextPromptChange
* [submit_questions](#submit_questions) - Resolve a halted questions cell. Submit hands the answers to the agent and  resumes it; Dismiss hands over only the answered count and does NOT resume  (the user's next message becomes the dismissal reason).
* [unbookmark](#unbookmark) - UnbookmarkChat
* [update](#update) - UpdateChat

                                                                                                                                       | A Timestamp represents a point in time independent of any time zone or local<br/> calendar, encoded as a count of seconds and fractions of seconds at<br/> nanosecond resolution. The count is relative to an epoch at UTC midnight on<br/> January 1, 1970, in the proleptic Gregorian calendar which extends the<br/> Gregorian calendar backwards to year one.<br/><br/> All minutes are 60 seconds long. Leap seconds are "smeared" so that no leap<br/> second table is needed for interpretation, using a [24-hour linear<br/> smear](https://developers.google.com/time/smear).<br/><br/> The range is from 0001-01-01T00:00:00Z to 9999-12-31T23:59:59.999999999Z. By<br/> restricting to that range, we ensure that we can convert to and from [RFC<br/> 3339](https://www.ietf.org/rfc/rfc3339.txt) date strings.<br/><br/> # Examples<br/><br/> Example 1: Compute Timestamp from POSIX `time()`.<br/><br/>     Timestamp timestamp;<br/>     timestamp.set_seconds(time(NULL));<br/>     timestamp.set_nanos(0);<br/><br/> Example 2: Compute Timestamp from POSIX `gettimeofday()`.<br/><br/>     struct timeval tv;<br/>     gettimeofday(&tv, NULL);<br/><br/>     Timestamp timestamp;<br/>     timestamp.set_seconds(tv.tv_sec);<br/>     timestamp.set_nanos(tv.tv_usec * 1000);<br/><br/> Example 3: Compute Timestamp from Win32 `GetSystemTimeAsFileTime()`.<br/><br/>     FILETIME ft;<br/>     GetSystemTimeAsFileTime(&ft);<br/>     UINT64 ticks = (((UINT64)ft.dwHighDateTime) << 32) \| ft.dwLowDateTime;<br/><br/>     // A Windows tick is 100 nanoseconds. Windows epoch 1601-01-01T00:00:00Z<br/>     // is 11644473600 seconds before Unix epoch 1970-01-01T00:00:00Z.<br/>     Timestamp timestamp;<br/>     timestamp.set_seconds((INT64) ((ticks / 10000000) - 11644473600LL));<br/>     timestamp.set_nanos((INT32) ((ticks % 10000000) * 100));<br/><br/> Example 4: Compute Timestamp from Java `System.currentTimeMillis()`.<br/><br/>     long millis = System.currentTimeMillis();<br/><br/>     Timestamp timestamp = Timestamp.newBuilder().setSeconds(millis / 1000)<br/>         .setNanos((int) ((millis % 1000) * 1000000)).build();<br/><br/> Example 5: Compute Timestamp from Java `Instant.now()`.<br/><br/>     Instant now = Instant.now();<br/><br/>     Timestamp timestamp =<br/>         Timestamp.newBuilder().setSeconds(now.getEpochSecond())<br/>             .setNanos(now.getNano()).build();<br/><br/> Example 6: Compute Timestamp from current time in Python.<br/><br/>     timestamp = Timestamp()<br/>     timestamp.GetCurrentTime()<br/><br/> # JSON Mapping<br/><br/> In JSON format, the Timestamp type is encoded as a string in the<br/> [RFC 3339](https://www.ietf.org/rfc/rfc3339.txt) format. That is, the<br/> format is "{year}-{month}-{day}T{hour}:{min}:{sec}[.{frac_sec}]Z"<br/> where {year} is always expressed using four digits while {month}, {day},<br/> {hour}, {min}, and {sec} are zero-padded to two digits each. The fractional<br/> seconds, which can go up to 9 digits (i.e. up to 1 nanosecond resolution),<br/> are optional. The "Z" suffix indicates the timezone ("UTC"); the timezone<br/> is required. A proto3 JSON serializer should always use UTC (as indicated by<br/> "Z") when printing the Timestamp type and a proto3 JSON parser should be<br/> able to accept both UTC and other timezones (as indicated by an offset).<br/><br/> For example, "2017-01-15T01:30:15.01Z" encodes 15.01 seconds past<br/> 01:30 UTC on January 15, 2017.<br/><br/> In JavaScript, one can convert a Date object to this format using the<br/> standard<br/> [toISOString()](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/toISOString)<br/> method. In Python, a standard `datetime.datetime` object can be converted<br/> to this format using<br/> [`strftime`](https://docs.python.org/2/library/time.html#time.strftime) with<br/> the time format spec '%Y-%m-%dT%H:%M:%S.%fZ'. Likewise, in Java, one can use<br/> the Joda Time's [`ISODateTimeFormat.dateTime()`](<br/> http://joda-time.sourceforge.net/apidocs/org/joda/time/format/ISODateTimeFormat.html#dateTime()<br/> ) to obtain a formatter capable of generating timestamps in this format. | **Example 1:** 2023-01-15T01:30:15.01Z<br/>**Example 2:** 2024-12-25T12:00:00Z
